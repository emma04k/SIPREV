SIPREV Architecture

Piloto de demo con datos sintéticos bajo reserva legal: Next.js, Auth.js, Prisma, PostgreSQL local, y preparación Vercel + Neon.

Control de acceso

  • • Auth.js Credentials con cuentas institucionales seed.
  • • requireUser y RBAC del lado servidor.
  • • /audit solo para SYSTEM_ADMIN y AUDITOR activos.
  • • Middleware protege rutas privadas solo como compuerta UX.

Flujos protegidos

  • • Registro de casos demo mediante transacción Prisma.
  • • Consulta y seguimiento autorizados por alcance institucional.
  • • AUDITOR conserva lectura amplia y queda write-blocked.
  • • Errores de UI/API son genéricos y seguros.

Persistencia y auditoría

  • • PostgreSQL local en Docker; Neon para demo desplegada.
  • • AuditLog registra CREATE, VIEW, UPDATE, REFER y SEED.
  • • La vista administrativa usa select mínimo y take 100.
  • • Metadata sanitizada: sin cuerpos enviados ni campos protegidos.
